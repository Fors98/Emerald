# Emerald design

## North star
A studio control room continuous with Emerald's dark green website and animated statue identity.

## Audience
One studio owner using desktop or Android. English UI, device-local dates, clear action labels, no invented endorsements.

## Runtime tokens
styles.css owns public tokens and self-hosted Fraunces/Manrope fonts, with OFL licenses. admin.css owns background #080e0c, panel #101b17, text #edf5ef, muted #b2c4b9, border #426e58, accent #86e4b9, danger #ffb5a7 and 10px radius. Georgia display, system-sans body.

## Layout and interaction
1200px width, 40px desktop/20px mobile padding, one column below 640px. Native selects intentionally use OS popups. Visible focus, live status, busy buttons, empty/error states and reduced-motion support. JavaScript-dependent buttons remain disabled until handlers are installed. No secrets in browser storage.
